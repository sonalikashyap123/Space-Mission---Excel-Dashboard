# Space Mission Analytics Dashboard

## Project Overview

The Space Mission Analytics Dashboard is an interactive Excel data analytics project built to analyze 1,200 space missions conducted by major space agencies.

The dashboard provides insights into mission volume, launch success, budget allocation, payload, mission duration, destinations, and mission trends over time.

## Dataset Used

The project uses a dataset containing **1,200 space mission records**.
- <a href="https://github.com/sonalikashyap123/Space-Mission---Excel-Dashboard/blob/main/Space%20Mission%20dataset.xlsx"> Dataset</a>

## Objectives

- Analyze space missions across different agencies and countries
- Track mission success and launch outcomes
- Compare mission budgets across agencies
- Analyze payload and mission duration
- Understand mission destinations
- Identify mission trends over time
- Provide interactive filtering for better data exploration

## Dashboard Features

### Key Performance Indicators

### Visualizations

## Key Insights

- The dataset contains 1,200 space missions.
- NASA has the highest number of missions in the dataset.
- The overall mission success rate is approximately 35.6%.
- LEO accounts for the largest share of mission destinations.
- Mission activity remains relatively consistent across most years.
- 2026 shows fewer missions because the dataset contains partial-year data.
